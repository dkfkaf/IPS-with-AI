# IPS 2단계 (대응형 IPS) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 1단계 관찰 전용 센서를, 플로우 통계로 포트 스캔·SYN 플러드를 탐지해 출발지 IP를 TTL 기반으로 차단하는 대응형 IPS로 확장한다.

**Architecture:** `PacketCapture::on_packet`이 판정 파이프라인(파싱 → 화이트리스트 → 차단목록 → 플로우 통계 → Rule 검사 → 차단)을 순서대로 수행한다. 순수 로직(파서·BlockList·FlowManager·Whitelist·Config·Rule)을 먼저 만들고 GTest로 검증한 뒤, 마지막에 NFQUEUE 경로에 배선한다. 단일 스레드를 유지하고, 만료 정리는 수신 루프의 틱 콜백으로 처리한다.

**Tech Stack:** C++17, libnetfilter_queue(NFQUEUE), glog(로깅), nlohmann/json(설정), Google Test(단위 테스트), CMake, pkg-config.

> **구현 후 반영된 두 가지 변경** (이 계획의 평평한 파일 경로와 다름): ① `src/`를 파이프라인

## Global Constraints

- **빌드·테스트는 Linux(Ubuntu) 대상에서만 가능** — 개발 머신은 Windows이고 WSL이 없어 로컬 컴파일 불가. Task 1~5는 root·NFQUEUE 불필요하므로 아무 Linux 박스(또는 Ubuntu VM)에서 `cmake --build` + `ctest`로 검증한다. Task 6~7만 root 권한과 NFQUEUE가 있는 방어 VM이 필요하다.
- **이름 규칙** (coding_style.md 1장): 변수·함수 snake_case, 클래스 PascalCase, 상수 UPPER_SNAKE, 파일 snake_case, C++ 멤버 변수 뒤 밑줄(`foo_`).
- **주석은 "왜"** 를 적는다. 매직 넘버는 두 곳 이상 일치해야 하거나 뜻이 불명확할 때만 상수화(사용처 1곳 + 문맥 명확하면 리터럴+주석).
- **struct/class**: 숨길 상태·불변식 없으면 struct(`FiveTuple`, `ParsedPacket`, `Flow`, `SourceStats`, `HeapEntry`, `Config`), 캡슐화 대상은 class(`FlowManager`, `Whitelist`, `BlockList`, `RuleEngine`).
- **바이트 순서**: 모든 `uint32_t` IP 키(Whitelist·BlockList·SourceStats·FiveTuple)는 **네트워크 바이트 순서**로 통일. 포트는 호스트 순서(1단계 관례). 문자열→IP 변환은 `inet_pton`.
- **fail-open**: 파싱 불가·상한 초과·관찰 불가 패킷은 통과(ACCEPT). 단 설정 로드 실패(깨진 JSON)는 시작 시점 **fail-fast**(종료).
- **컴파일 경고**: `-Wall -Wextra` (기존 CMakeLists 유지). 새 코드도 경고 없이 컴파일돼야 한다.
- **커밋**: 각 태스크(때로 각 스텝) 종료 시 커밋. 기능 커밋과 리팩토링 커밋을 섞지 않는다.
- **설계 근거 문서**: `stage2.md`(2단계 상세 설계). 이 계획은 그 설계의 구현판이다.

```cpp
#ifndef IPS_SRC_PACKET_PARSER_H_
#define IPS_SRC_PACKET_PARSER_H_

#include <cstddef>
#include <cstdint>
#include <optional>

#include "five_tuple.h"

// 파싱 결과. FiveTuple(플로우 키)에 플로우 통계용 필드를 한 겹 감싼다.
// tcp_ack는 두지 않는다 — SYN 플러드 판정이 SYN 플래그 선 패킷을 전부 세므로 소비자가 없다.
struct ParsedPacket {
    FiveTuple tuple;      // has_ports=false면 src_port/dst_port는 0
    uint16_t total_len;   // IP 전체 길이 (ntohs로 호스트 순서 변환 후 저장)
    bool has_ports;       // 전송 계층(TCP/UDP) 파싱 성공 여부
    bool tcp_syn;         // TCP SYN 플래그 (UDP거나 has_ports=false면 false)
};

// 원시 패킷 바이트(IP 헤더부터)에서 ParsedPacket을 만든다.
// 기본 IP 헤더 20바이트가 유효하게 읽히지 않을 때(길이 부족·version≠4·ihl<5)만 nullopt.
// 전송 헤더를 못 읽으면 has_ports=false로 반환한다(출발지 IP는 유효).
struct PacketParser {
    std::optional<ParsedPacket> parse(const uint8_t* data, size_t len) const;
};

#endif  // IPS_SRC_PACKET_PARSER_H_
```

`src/packet_parser.cpp`를 아래로 교체:

```cpp
#include "packet_parser.h"

#include <arpa/inet.h>
#include <netinet/in.h>
#include <netinet/ip.h>
#include <netinet/tcp.h>
#include <netinet/udp.h>

namespace {

// iphdr의 ihl 필드는 4바이트 단위로 헤더 길이를 표현한다
constexpr size_t IHL_UNIT_BYTES = 4;

}  // namespace

std::optional<ParsedPacket> PacketParser::parse(const uint8_t* data, size_t len) const {
    // 기본 IP 헤더(20바이트)보다 짧으면 필드 접근 자체가 범위를 벗어난다
    if (data == nullptr || len < sizeof(struct iphdr)) {
        return std::nullopt;
    }
    const auto* ip_header = reinterpret_cast<const struct iphdr*>(data);
    if (ip_header->version != IPVERSION) {
        return std::nullopt;  // IPv6 등은 대상 아님
    }
    const size_t ip_header_len = static_cast<size_t>(ip_header->ihl) * IHL_UNIT_BYTES;
    if (ip_header_len < sizeof(struct iphdr)) {
        return std::nullopt;  // ihl<5는 규격 위반 — 신뢰할 수 없는 헤더
    }

    // 여기부터는 기본 20바이트가 읽히므로 출발지 IP·프로토콜·전체 길이를 얻을 수 있다.
    // 전송 헤더를 못 읽는 경우는 nullopt이 아니라 has_ports=false로 돌려준다(차단 우회 방지).
    ParsedPacket packet = {};
    packet.tuple.src_ip = ip_header->saddr;   // 네트워크 바이트 순서 그대로
    packet.tuple.dst_ip = ip_header->daddr;
    packet.tuple.protocol = ip_header->protocol;
    packet.total_len = ntohs(ip_header->tot_len);  // 네트워크→호스트 순서
    packet.has_ports = false;
    packet.tcp_syn = false;

    // 뒤쪽 IP 조각에는 전송 헤더가 없다
    if ((ntohs(ip_header->frag_off) & IP_OFFMASK) != 0) {
        return packet;
    }
    // ihl이 버퍼보다 긴 헤더(옵션 잘림)를 주장하면 전송 헤더 위치를 잡을 수 없다
    if (len < ip_header_len) {
        return packet;
    }

    const uint8_t* transport = data + ip_header_len;
    const size_t transport_len = len - ip_header_len;

    if (packet.tuple.protocol == IPPROTO_TCP) {
        if (transport_len < sizeof(struct tcphdr)) {
            return packet;  // 잘린 TCP 헤더
        }
        const auto* tcp_header = reinterpret_cast<const struct tcphdr*>(transport);
        packet.tuple.src_port = ntohs(tcp_header->source);
        packet.tuple.dst_port = ntohs(tcp_header->dest);
        packet.tcp_syn = tcp_header->syn != 0;
        packet.has_ports = true;
    } else if (packet.tuple.protocol == IPPROTO_UDP) {
        if (transport_len < sizeof(struct udphdr)) {
            return packet;  // 잘린 UDP 헤더
        }
        const auto* udp_header = reinterpret_cast<const struct udphdr*>(transport);
        packet.tuple.src_port = ntohs(udp_header->source);
        packet.tuple.dst_port = ntohs(udp_header->dest);
        packet.has_ports = true;
    }
    // TCP/UDP 외(ICMP 등)는 has_ports=false로 둔다 — 포트가 없어 규칙 판정 대상이 아니다
    return packet;
}
```

```cpp
#ifndef IPS_SRC_BLOCK_LIST_H_
#define IPS_SRC_BLOCK_LIST_H_

#include <cstdint>
#include <queue>
#include <unordered_map>
#include <vector>

#include "clock.h"

// 힙 항목: 만료 시각으로 정렬. std::greater로 min-heap을 만들기 위해 operator>를 준다.
struct HeapEntry {
    TimePoint expiry;
    uint32_t ip;
    bool operator>(const HeapEntry& other) const { return expiry > other.expiry; }
};

// 차단 IP 관리 (map + min-heap + 지연 삭제, overview.md 6.2).
// map이 진실의 원천, heap은 만료 순 정리를 위한 보조 색인.
class BlockList {
 public:
    void block(uint32_t ip, int ttl_seconds, TimePoint now);  // 신규 차단 또는 만료 연장
    bool is_blocked(uint32_t ip, TimePoint now);              // O(1), 만료면 false
    void cleanup_expired(TimePoint now);                      // 힙 상단만 확인

 private:
    std::unordered_map<uint32_t, TimePoint> block_map_;  // IP → 만료 시각 (진실의 원천)
    std::priority_queue<HeapEntry, std::vector<HeapEntry>, std::greater<HeapEntry>> expiry_heap_;
};

#endif  // IPS_SRC_BLOCK_LIST_H_
```

`src/block_list.cpp`:

```cpp
#include "block_list.h"

#include <arpa/inet.h>

#include <glog/logging.h>

void BlockList::block(uint32_t ip, int ttl_seconds, TimePoint now) {
    const TimePoint expiry = now + std::chrono::seconds(ttl_seconds);
    const auto it = block_map_.find(ip);
    const bool is_new = (it == block_map_.end());
    block_map_[ip] = expiry;                 // 신규든 연장이든 map을 최신 만료로 갱신
    expiry_heap_.push(HeapEntry{expiry, ip});  // 힙엔 항상 push — 낡은 항목은 지연 삭제
    if (is_new) {
        // 차단 등록 시 1회만 로그 (차단된 패킷마다 찍으면 DDoS 시 로그 폭주)
        struct in_addr addr;
        addr.s_addr = ip;
        LOG(WARNING) << "차단 등록: " << inet_ntoa(addr) << " (TTL " << ttl_seconds << "s)";
    }
}

bool BlockList::is_blocked(uint32_t ip, TimePoint now) {
    const auto it = block_map_.find(ip);
    if (it == block_map_.end()) {
        return false;
    }
    return now < it->second;  // 만료 시각 이전이면 차단 중 (실제 제거는 cleanup에 맡김)
}

void BlockList::cleanup_expired(TimePoint now) {
    while (!expiry_heap_.empty() && expiry_heap_.top().expiry <= now) {
        const HeapEntry entry = expiry_heap_.top();
        expiry_heap_.pop();
        const auto it = block_map_.find(entry.ip);
        // map 값과 대조 — 일치할 때만 실제 해제. 불일치면 연장으로 생긴 낡은 항목이라 버린다.
        if (it != block_map_.end() && it->second == entry.expiry) {
            struct in_addr addr;
            addr.s_addr = entry.ip;
            LOG(INFO) << "차단 해제(TTL 만료): " << inet_ntoa(addr);
            block_map_.erase(it);
        }
    }
}
```

`src/flow_manager.cpp`:

```cpp
#include "flow_manager.h"

#include <chrono>

FlowManager::FlowManager(int window_seconds, size_t max_flows, size_t max_sources)
    : window_seconds_(window_seconds), max_flows_(max_flows), max_sources_(max_sources) {}

const SourceStats* FlowManager::add_packet(const ParsedPacket& packet, TimePoint now) {
    const uint32_t src_ip = packet.tuple.src_ip;

    // --- 출발지 통계 ---
    auto it = source_stats_.find(src_ip);
    if (it == source_stats_.end()) {
        if (source_stats_.size() >= max_sources_) {
            return nullptr;  // 상한 초과 — 신규 출발지 통계를 만들지 않는다 (명시적 fail-open)
        }
        it = source_stats_.emplace(src_ip, SourceStats{}).first;
        it->second.window_start = now;
    } else if (now - it->second.window_start >=
               std::chrono::seconds(window_seconds_)) {
        // 고정 창 리셋: 통계를 비우고 창을 지금부터 다시 시작
        it->second.recent_dst_ports.clear();
        it->second.syn_count = 0;
        it->second.window_start = now;
    }
    SourceStats& stats = it->second;
    stats.recent_dst_ports.insert(packet.tuple.dst_port);
    if (packet.tcp_syn) {
        ++stats.syn_count;  // SYN 플래그 선 패킷 전부 카운트 (SYN+ACK 포함, -SA 플러드 방어)
    }

    // --- 플로우 통계 (2단계 규칙은 읽지 않지만 메모리 위생·AI 토대) ---
    auto flow_it = flows_.find(packet.tuple);
    if (flow_it == flows_.end()) {
        if (flows_.size() < max_flows_) {  // 상한 넘으면 새 플로우는 조용히 생략
            Flow flow;
            flow.tuple = packet.tuple;
            flow.first_seen = now;
            flow_it = flows_.emplace(packet.tuple, flow).first;
        }
    }
    if (flow_it != flows_.end()) {
        Flow& flow = flow_it->second;
        ++flow.packet_count;
        flow.byte_count += packet.total_len;
        flow.last_seen = now;
    }

    return &stats;
}

void FlowManager::cleanup_expired(TimePoint now) {
    // 마지막 패킷 이후 FLOW_TIMEOUT_SEC 지난 플로우 제거
    const auto flow_timeout = std::chrono::seconds(FLOW_TIMEOUT_SEC);
    for (auto it = flows_.begin(); it != flows_.end();) {
        it = (now - it->second.last_seen >= flow_timeout) ? flows_.erase(it) : std::next(it);
    }
    // 창이 끝난 출발지 통계 제거 (다음 패킷이 어차피 리셋하므로 미리 지워도 안전)
    const auto window = std::chrono::seconds(window_seconds_);
    for (auto it = source_stats_.begin(); it != source_stats_.end();) {
        it = (now - it->second.window_start >= window) ? source_stats_.erase(it)
                                                       : std::next(it);
    }
}
```

```cpp
bool Whitelist::load(const std::vector<std::string>& ip_strings) {
    ips_.clear();
    bool ok = true;
    for (const std::string& s : ip_strings) {
        struct in_addr addr;
        // inet_pton은 네트워크 바이트 순서를 그대로 준다 — 파서 src_ip와 동일 순서.
        if (inet_pton(AF_INET, s.c_str(), &addr) == 1) {
            ips_.insert(addr.s_addr);
        } else {
            LOG(ERROR) << "화이트리스트 IP 형식 오류: " << s;
            ok = false;  // 오타 하나로 관리자 IP 보호가 무음 무력화되는 것을 막는다
        }
    }
    return ok;
}

bool Whitelist::is_whitelisted(uint32_t ip) const {
```

```cpp
#include "config.h"

#include <fstream>
#include <sstream>

#include <glog/logging.h>
#include <nlohmann/json.hpp>

std::optional<Config> parse_config(const std::string& json_text) {
    Config cfg;  // 필드별 기본값에서 시작 — 없는 키는 기본값 유지
    try {
        const auto j = nlohmann::json::parse(json_text);
        cfg.queue_num = j.value("queue_num", cfg.queue_num);
        cfg.block_ttl_seconds = j.value("block_ttl_seconds", cfg.block_ttl_seconds);
        cfg.whitelist = j.value("whitelist", cfg.whitelist);
        if (j.contains("rules")) {
            const auto& r = j.at("rules");
            cfg.window_seconds = r.value("window_seconds", cfg.window_seconds);
            if (r.contains("port_scan")) {
                cfg.distinct_port_threshold =
                    r.at("port_scan").value("distinct_port_threshold",
                                            cfg.distinct_port_threshold);
            }
            if (r.contains("syn_flood")) {
                cfg.syn_threshold =
                    r.at("syn_flood").value("syn_threshold", cfg.syn_threshold);
            }
        }
    } catch (const nlohmann::json::exception& e) {
        LOG(ERROR) << "config.json 파싱 실패: " << e.what();
        return std::nullopt;  // 깨진 설정으로 조용히 도는 것보다 시작 중단이 안전
    }
    return cfg;
}

std::optional<Config> load_config(const std::string& path) {
    std::ifstream file(path);
    if (!file.is_open()) {
        LOG(WARNING) << "config.json 없음 (" << path << ") — 기본값으로 동작";
        return Config{};  // 파일 없음은 fail-open (일단 돌려보기)
    }
    std::ostringstream ss;
    ss << file.rdbuf();
    return parse_config(ss.str());
}
```

```cpp
bool PacketSource::loop() {
    running_ = true;
    bool ok = true;
    alignas(4) char buffer[RECV_BUFFER_BYTES];

    using Clock = std::chrono::steady_clock;
    auto last_cleanup = Clock::now();
    // ENOBUFS 요약용 상태: 마지막 경고 시각과 그 사이 누적 발생 횟수
    auto last_enobufs_log = Clock::now();
    uint64_t enobufs_since_log = 0;

    while (running_) {
        const ssize_t received = recv(fd_, buffer, sizeof(buffer), 0);
        if (received > 0) {
            nfq_handle_packet(handle_, buffer, static_cast<int>(received));
        } else if (received == 0) {
            LOG(ERROR) << "넷링크 소켓이 닫힘 — 수신 루프 종료";
            ok = false;
            break;
        } else if (errno == EAGAIN || errno == EWOULDBLOCK || errno == EINTR) {
            // 타임아웃/시그널 — running_ 재확인하고 아래 틱 처리로 진행
        } else if (errno == ENOBUFS) {
            // 발생마다 찍지 않고 주기 요약 — 플러드 시 이 경고 자체가 로그 폭주가 된다
            ++enobufs_since_log;
            const auto now = Clock::now();
            if (now - last_enobufs_log >= std::chrono::seconds(ENOBUFS_LOG_INTERVAL_SEC)) {
                LOG(WARNING) << "커널 수신 버퍼 넘침 — 최근 " << ENOBUFS_LOG_INTERVAL_SEC
                             << "초간 " << enobufs_since_log << "회 패킷 유실";
                enobufs_since_log = 0;
                last_enobufs_log = now;
            }
        } else {
            LOG(ERROR) << "recv 실패: " << std::strerror(errno);
            ok = false;
            break;
        }

        // 주기 정리: 트래픽이 있으면 recv 사이에, 유휴면 타임아웃 직후에 불린다
        const auto now = Clock::now();
        if (now - last_cleanup >= std::chrono::seconds(CLEANUP_INTERVAL_SEC)) {
            if (tick_handler_) {
                tick_handler_();
            }
            last_cleanup = now;
        }
    }
    running_ = false;
    return ok;
}
```

- [ ] **Step 2: PacketCapture 구현 교체**

`src/packet_capture.cpp`:

```cpp
#include "packet_capture.h"

#include <memory>
#include <optional>

#include <glog/logging.h>

#include "port_scan_rule.h"
#include "syn_flood_rule.h"

PacketCapture::PacketCapture(const Config& config)
    : block_ttl_seconds_(config.block_ttl_seconds),
      flow_manager_(config.window_seconds),
      source_(config.queue_num,
              [this](const uint8_t* data, size_t len) { return on_packet(data, len); },
              [this]() { on_tick(); }) {
    // 화이트리스트 적재 실패는 main에서 시작 전에 걸러야 하지만, 방어적으로 한 번 더 기록.
    if (!whitelist_.load(config.whitelist)) {
        LOG(ERROR) << "화이트리스트에 잘못된 IP가 있습니다 — 설정을 확인하세요";
    }
    rule_engine_.add_rule(std::make_unique<PortScanRule>(config.distinct_port_threshold));
    rule_engine_.add_rule(std::make_unique<SynFloodRule>(config.syn_threshold));
}

bool PacketCapture::start() {
    if (!source_.open()) {
        return false;
    }
    const bool loop_ok = source_.loop();
    const bool close_ok = source_.close();
    return loop_ok && close_ok;
}

void PacketCapture::stop() { source_.stop(); }

bool PacketCapture::on_packet(const uint8_t* data, size_t len) {
    const std::chrono::steady_clock::time_point now = std::chrono::steady_clock::now();

    const std::optional<ParsedPacket> parsed = parser_.parse(data, len);
    if (!parsed.has_value()) {
        return true;  // IP 헤더도 못 읽음 — 진짜 관찰 불가 트래픽만 fail-open
    }
    const uint32_t src_ip = parsed->tuple.src_ip;

    if (whitelist_.is_whitelisted(src_ip)) {
        return true;  // 어떤 판정보다 먼저 — 관리자 IP 오탐 차단의 최종 안전장치
    }
    if (block_list_.is_blocked(src_ip, now)) {
        return false;  // 차단 중 — ICMP·조각도 여기서 DROP (프로토콜 우회 방지)
    }
    if (!parsed->has_ports) {
        return true;  // 포트 없음 — 규칙 판정 불가, 관찰만 생략
    }

    const SourceStats* stats = flow_manager_.add_packet(*parsed, now);
    if (stats == nullptr) {
        return true;  // MAX_SOURCES 초과 — 명시적 fail-open
    }

    const Rule* hit = rule_engine_.check(*stats);
    if (hit != nullptr) {
        block_list_.block(src_ip, block_ttl_seconds_, now);
        LOG(WARNING) << "규칙 '" << hit->name() << "' 위반 → 차단: " << parsed->tuple.to_string();
        return false;
    }
    return true;
}

void PacketCapture::on_tick() {
    const std::chrono::steady_clock::time_point now = std::chrono::steady_clock::now();
    block_list_.cleanup_expired(now);
    flow_manager_.cleanup_expired(now);
}
```

- [ ] **Step 3: main.cpp 교체 — Config 로드 + fail-fast**

`src/main.cpp`:

```cpp
#include <unistd.h>

#include <csignal>

#include <glog/logging.h>

#include "config.h"
#include "packet_capture.h"
#include "whitelist.h"

namespace {

PacketCapture* g_capture = nullptr;

void handle_signal(int /*signum*/) {
    if (g_capture != nullptr) {
        g_capture->stop();
    }
}

}  // namespace

int main(int /*argc*/, char* argv[]) {
    google::InitGoogleLogging(argv[0]);
    FLAGS_logtostderr = true;

    if (geteuid() != 0) {
        LOG(WARNING) << "root 권한이 아닙니다 — NFQUEUE 열기에 실패할 수 있습니다";
    }

    // 설정 로드: 파일 없음 → 기본값, 깨진 JSON → 시작 중단(fail-fast)
    const auto config = load_config("config.json");
    if (!config.has_value()) {
        LOG(ERROR) << "설정이 깨져 있습니다 — 시작을 중단합니다";
        return 1;
    }
    // 화이트리스트 형식 검증도 시작 전에: 잘못된 IP가 있으면 중단(오타로 인한 무음 무력화 방지)
    Whitelist check;
    if (!check.load(config->whitelist)) {
        LOG(ERROR) << "화이트리스트 IP 형식 오류 — config.json을 고치고 다시 실행하세요";
        return 1;
    }

    PacketCapture capture(*config);
    g_capture = &capture;
    std::signal(SIGINT, handle_signal);
    std::signal(SIGTERM, handle_signal);

    LOG(INFO) << "AI 기반 인라인 IPS — 2단계: 대응형 IPS (포트 스캔·SYN 플러드 차단)";
    LOG(INFO) << "트래픽 유입 규칙 예: sudo iptables -I INPUT -j NFQUEUE --queue-num "
              << config->queue_num << " --queue-bypass";

    if (!capture.start()) {
        return 1;
    }
    LOG(INFO) << "정상 종료";
    return 0;
}
```
